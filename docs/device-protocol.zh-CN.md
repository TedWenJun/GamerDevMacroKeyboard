# W909 设备协议说明

[English](device-protocol.md) | 中文

MacroHub 直接与 W909 通信，不需要安装厂商软件。本文说明 MacroHub 用到的设备端接口：按键输入、背光控制与状态查询。

## 设备标识

| 连接方式 | 设备路径特征 | 说明 |
|---|---|---|
| USB 有线 | `VID_B6A4&PID_4100` | |
| 2.4G 接收器 | `VID_B6A4&PID_4101` | 集合与报告格式与有线完全相同 |
| 蓝牙 | `VID&0002B6A4`（经典）/ `VID&02B6A4`（BLE） | 尚未验证 |

## 输入

| 集合 | 内容 |
|---|---|
| Usage Page `0xFF00`，Report ID `5` | 厂商位图：每个物理开关一个位，按下为 1。MacroHub 以位号作为控件的物理身份 |
| Consumer Control（`0x0C/0x01`），Report ID `3` | 旋钮左右旋发送音量 −/+（`0x00EA` / `0x00E9`） |
| 键盘集合 | 小键盘键码与方向键，由 Windows 独占，MacroHub 通过低级键盘钩子关联拦截 |

旋钮每转一格，固件先发送一份全零的厂商位图，约 1 ms 后再发送音量报告。按住旋钮旋转时，这份全零报告会让"旋钮按下"位看起来已松开。MacroHub 把"松开后 10 ms 内紧跟旋转"的报告视为转动帧，保持按下状态，直到真正的松开报告到来。

## 厂商 Feature 通道

| 项 | 值 |
|---|---|
| 集合 | `MI_02 COL04`，Usage Page `0xFF01` / Usage `0x01` |
| 报告 | Feature，Report ID `0x06`，41 字节（1 字节报告号 + 40 字节载荷） |
| 访问 | 用户态 `CreateFile` + `HidD_SetFeature` / `HidD_GetFeature`，无需驱动或提权 |

### 帧格式

```
[0]  0x06          报告号
[1]  0x00
[2]  0x01
[3]  命令
[4]  序号          每帧 +1；应答回显同一序号
[5]  0x00 / 0x01   写配置块用 0x00，应用命令用 0x01
[6]  地址低字节
[7]  地址高字节
[8]  数据长度
[9..] 数据
```

| 命令 | 含义 |
|---|---|
| `0x09` | 写灯光配置块 |
| `0x02` | 应用（数据 2 字节，不是校验和，填 `00 00` 即可） |
| `0x81` | 状态查询（只读，见下文） |

同一通道上还有按键映射表等其他命令。MacroHub 只发送上表中的三个命令，从不修改按键映射。

### 灯光地址布局

| 地址 | 长度 | 内容 |
|---|---|---|
| `0x00` | 25 | 当前模式：`<0x80 + N> FF 01 00…` |
| `0x19 × N` | 25 | 第 N 号模式的参数块 |

| N | 模式 |
|---|---|
| 1 | 单色常亮 |
| 2 | 行云流水 |
| 3 | 跑马 |
| 4 | 单色呼吸 |
| 5 | 循环呼吸 |
| 6 | 俄罗斯方块 |
| 7 | 霓虹 |
| 8 | 流光溢彩 |
| 9 | 关灯（无参数块） |

参数块（25 字节）：

| 偏移 | 含义 |
|---|---|
| 0 | 速度 `0–5` |
| 1 | 方向 `0 / 1`（流动类模式） |
| 2 | 亮度 `0–5`，共 6 档，**0 最亮** |
| 3 | 色槽启用掩码，每槽 1 位；`0x7F` = 七槽全开 |
| 4–24 | 7 组颜色，每组 R、G、B 各 1 字节 |

单色类模式只点亮已启用的色槽，MacroHub 把同一颜色写入全部 7 槽。

### 写入时序

每次改动发送三帧，帧之间间隔几毫秒（背靠背发送会丢帧）：

1. `0x09` 写地址 `0x00`：选择模式
2. `0x09` 写地址 `0x19 × N`：该模式的参数块（关灯模式跳过）
3. `0x02`：应用

### 状态查询与电量

发送命令 `0x81`（数据 3 字节全零），约 30 ms 后用 `HidD_GetFeature` 读回。应答回显命令与序号，数据 3 字节：

| 字节 | 含义 |
|---|---|
| 0 | 连接：`0` 有线，`1` 2.4G |
| 1 | bit 7 = 充电中，bit 0–6 = 电量百分比 |
| 2 | `0` |

示例：有线 `00 E4 00`（充电中，100%）；2.4G `01 53 00`（83%）。2.4G 模式下键盘休眠时不应答，MacroHub 在下一次按键唤醒后立即重新查询。
